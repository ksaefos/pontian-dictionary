# Ορθογραφικός έλεγχος

Στη διαχείριση συνδέσου και επίλεξε **Ορθογραφικός έλεγχος**. Άρχισε από τις **Ελεγμένες προτάσεις**. Κάθε ομάδα συγκεντρώνει όλες τις εμφανίσεις του ίδιου τύπου. Μπορείς να ανοίξεις την εγγραφή ή να περάσεις μία πρόταση στο πεδίο του editor. Η δημοσίευση γίνεται μόνο με την κανονική αποθήκευση του λήμματος.

Η **Αποδοχή τύπου** αποθηκεύει την ακριβή γραφή στον συγκεκριμένο browser για να σταματήσει να εμφανίζεται ως άγνωστη. Η επιλογή **Εμφάνιση αποδεκτών** επιτρέπει ανάκληση. Η εξαγωγή JSON μπορεί να δοθεί σε επόμενη σάρωση μέσω `--accepted`.

## Πρώτη σάρωση

Ελέγχθηκαν 29.700 ενεργές εγγραφές από τις δύο ταυτόσημες ενσωματωμένες βάσεις και το παραγωγικό overlay με ημερομηνία `2026-11-12T19:57:51.063Z`. Η διαγραμμένη εγγραφή εξαιρέθηκε.

| Έλεγχος | Εμφανίσεις | Ομάδες |
|---|---:|---:|
| Ελεγμένη αντικατάσταση «διακρητικό» → «διακριτικό» | 4 | 1 |
| Άγνωστοι τύποι στο νεοελληνικό Hunspell | 5.843 | 3.388 |
| Απλή απόστροφος, πολλαπλά κενά και επιλεγμένοι αόρατοι χαρακτήρες | 0 | 0 |

Τα αποτελέσματα Hunspell είναι ευρήματα προς ταξινόμηση. Μεταξύ των πρώτων ομάδων υπάρχουν συντομογραφίες όπως «παθ» και «αμετ», ποντιακοί τύποι όπως «παρχάρι» και μορφές που χρειάζονται γλωσσικό έλεγχο. Η αναφορά περιέχει προτάσεις Hunspell όπου βρέθηκαν για έως 100 από τις συχνότερες ομάδες. Στον editor ελέγχονται άμεσα οι τυπογραφικοί κανόνες και οι τύποι που είναι ήδη γνωστοί από την αναφορά. Η πλήρης σάρωση νέου κειμένου γίνεται με το εργαλείο παραγωγής της αναφοράς.

## Αναπαραγωγή

Χρειάζονται Python 3, κοινόχρηστη βιβλιοθήκη Hunspell 1.7 και τα αρχεία `el_GR.aff` και `el_GR.dic`. Για το αρχικό αποτέλεσμα χρησιμοποιήθηκαν τα αρχεία του LibreOffice στο commit [c0865a8](https://github.com/LibreOffice/dictionaries/tree/c0865a85eb67dc377f2cf8e8fe2c4fa9e53f0dcb/el_GR), με τις άδειες που δηλώνονται στο README του λεξικού. Η γλωσσική βάση Hunspell αποκτάται χωριστά.

```sh
python3 tools/scan-spelling.py --dictionary /path/to/el_GR
python3 tools/scan-spelling.py --dictionary /path/to/el_GR --accepted /path/to/pontian-accepted-words.json
```

Το εργαλείο διαβάζει τη βάση και το overlay του checkout και ανανεώνει μόνο το `admin/proofreading-report.json`. Μια πρόταση μεταφέρεται αυτόματα στον editor μόνο αν το πεδίο έχει ακριβώς την τιμή που είχε κατά τη σάρωση. Αν η τιμή έχει αλλάξει, η εφαρμογή επιτρέπει να ανοίξεις την τρέχουσα εγγραφή για έλεγχο.

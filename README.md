# Ποντιακό Λεξικό – Ενημέρωση σύνδεσης διαχειριστή (v5.1.2)

## Αρχεία προς αντικατάσταση στο main (root)
- `index.html` → αντικατάσταση του υπάρχοντος.
- `cloud-sync.js` → αντικατάσταση του υπάρχοντος.
- `sw.js` → αντικατάσταση του υπάρχοντος, για ανανέωση της cache PWA.

## Αρχεία που ΔΕΝ αλλάζουν
- `data/edits.json`: ΜΗΝ το αντικαταστήσεις ή διαγράψεις. Περιέχει τις διορθώσεις σου.
- `manifest.webmanifest`, `icons/`, `.nojekyll`: καμία αλλαγή.
- Cloudflare Worker και Secrets: καμία αλλαγή. Συνδέεσαι με το υπάρχον `EDITOR_KEY`.

## Τι βλέπεις
- Όνομα χρήστη `ksaefos` ήδη συμπληρωμένο, μη επεξεργάσιμο.
- Πεδίο «Κωδικός πρόσβασης» ακριβώς από κάτω.
- Η διεύθυνση του Worker είναι σταθερή στον client: https://pontian-dictionary-sync.ksaefos.workers.dev.

Το όνομα χρήστη είναι ένδειξη στο περιβάλλον και όχι δεύτερος παράγοντας ελέγχου ταυτότητας. Ο Worker συνεχίζει να επικυρώνει τον κωδικό μέσω EDITOR_KEY.

## Έλεγχος
1. Ανέβασε τα 3 αρχεία στο root του repository και κάνε commit.
2. Μετά το Pages deployment, κάνε πλήρη ανανέωση, ή κλείσε και ξανάνοιξε την εγκατεστημένη PWA.
3. Άνοιξε «Διαχείριση». Βεβαιώσου ότι βλέπεις `ksaefos` και τον κωδικό.
4. Συνδέσου με το ισχύον `EDITOR_KEY` και έλεγξε ότι φορτώνονται οι δημοσιευμένες αλλαγές.
5. Κάνε μια πραγματική διόρθωση και έλεγξε τη δημοσίευση στο `data/edits.json`.

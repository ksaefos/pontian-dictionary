# Ποντιακό Λεξικό v5.1 — PWA

Για το repository https://github.com/ksaefos/pontian-dictionary

**Ανέβασε / αντικατάστησε στον βασικό φάκελο:**
- `index.html` (αντικαθιστά το παλιό)
- `cloud-sync.js` (ίδιο με την v5.0)
- `manifest.webmanifest` (νέο)
- `sw.js` (νέο)
- `icons/icon-192.png`, `icons/icon-512.png` (νέα)
- `.nojekyll` (όπως ήδη υπάρχει)

**ΠΡΟΣΟΧΗ:** ΜΗΝ αντικαταστήσεις το ήδη δημοσιευμένο `data/edits.json`. Περιέχει τις πραγματικές διορθώσεις σου. Το πακέτο σκόπιμα δεν το περιλαμβάνει. ΜΗΝ αλλάξεις Worker, GitHub token ή EDITOR_KEY.

Μετά τη δημοσίευση στο GitHub Pages άνοιξε https://ksaefos.github.io/pontian-dictionary/ από Chrome και ανανέωσε. Στο Android μενού ⋮ → Εγκατάσταση εφαρμογής (ενδεχομένως εμφανίζεται μέσω «Προσθήκη στην αρχική οθόνη»). Αν είχε δημιουργηθεί προηγούμενη συντόμευση, αφαίρεσέ την και εγκατάστησε ξανά.

Offline: ο Service Worker κρατά την εφαρμογή και τα λήμματα ενσωματωμένα στο index.html. Μπορείς να διαβάζεις και να αναζητάς χωρίς σύνδεση, εφόσον φορτώθηκε πρώτα online. Ενημέρωση από GitHub και αποθήκευση επεξεργασιών απαιτούν Internet. Δεν μπαίνουν tokens/κωδικοί στην cache του Service Worker.

Εικονίδιο προσωρινό, καθαρό σύμβολο ανοικτού βιβλίου.
